# Split It — legacy personal web application

## Repository status — 2026-10-15

`willyros01/split` is the original personal shared-expense web application. It is **not** the source branch for the public Fairpot Android or iOS distribution. The maintained Fairpot app lives in its separate existing `willyros01/fairpot` repository: `main` for iOS/TestFlight and `android` for permanently signed Fire HD 8 APK migration.
